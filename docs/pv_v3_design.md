# v3 分镜设计 —— 特效 PV 剪辑视角

主题不变：「我眼中，青梅竹马视角的她」。
前半段的水墨（0–30.9 s）已经认可，保持不动。那一段是"记忆"。
从 31.1 s 那一下鼓开始，她走出水墨，进入真正的三维世界，这一段是"此刻"。
3D 部分全部在 Blender 5.2 里制作（Blender MCP 驱动，Eevee 渲染），每一帧仍然是歌曲时间的函数：
歌词逐字时间、鼓点、段落都写进关键帧。

## 剪辑原则

- 大事件只放在三个点：31.1 s（鼓回来那一下）、47.2 s（drop）、69.3 s（最后一句）。
  其余时间镜头连续运动，不跟着每个鼓点抖。
- 切点落在小节线（每 1.87 s 一小节）或歌词句首。镜头运动有动机：跟随、揭示、绕行、推进。
- 色彩脚本：
  - 雨夜：蓝黑底色，一盏钠灯（琥珀色）。
  - drop：白闪之后是黑底上的暖光建筑。
  - 棋局：月白色。
  - 光笔：蓝图青色转为暖色。
  - 回眸：全片唯一一次全彩，金色逆光。
- 她多数时候是逆光剪影加橙色轮廓光。全彩只留给最后的回眸。

## 3D 形象

形象严格按 `input/character_claude.jpg` 制作：

1. 用绘画 AI 以原图为参考，生成"3D 建模参考图"式的四视图：
   - 正、左、背、右四个视图，正交投影，无光影。
   - 透明背景，最高质量。
   - 文件：`assets/poses/modelsheet_<姿势>.png`。
2. 切成 Tripo 多视图输入，放在 `assets/tripo/input/<姿势>/`。
3. 由你在 Tripo 网页生成模型（GLB），放到 `assets/tripo/<姿势>.glb`。
4. 通过 Blender MCP 导入，统一尺寸和朝向，再接上特效材质：剪影、轮廓光、显形扫描、心口注光、蓝图线稿、全彩。

在 Tripo 模型到位之前，场景里用的是本地 Hunyuan3D-2mv 生成的临时模型。

她不由代码"画"出来：几何和颜色都来自 AI 多视图生成的模型。

| 模型 | 姿势 | 用在 |
|---|---|---|
| stand | 原图站姿，右手抱书 | S5 drop、S6 光茧、S8–S9 光笔 |

## 高潮段字体：「空间书法」

L11–L16 不再是贴在画面上的字幕。字是她世界里真实存在的三维物体：

- 字体：思源宋体 Black（Noto Serif TC），挤出并倒角。
- 字被场景灯照亮，在地面上有倒影，受景深和运动模糊影响。
- 入场：每个字在它被唱出的那一刻，先由一道光沿字的轮廓描出来（呼应"光笔"），再点亮字身。
- 出场：化成光尘，光尘成为下一段特效的材料。
- 版式随镜头变化：L11 字碑，L12 字环，L13 棋子，L14–15 空中书写，L16 灯笼。
- 每句都会留出一段完整、正面、可读的停留。

L6–L10 继续使用已经认可的电影感思源宋体字幕。

## v3.1 修订（2026-10-12）：45 s 之后不露模型细节，2D 原画与 3D 世界融合

反馈：模型细节难看，45 s 之后不要完整露出模型；如需出现她，用剪影等形式，优先用原素材 `input/character_claude.jpg`；
字体加入代码特效元素。

### 融合方案「我眼中的她」

3D 是她所在的世界，2D 原画是"我看她的方式"。45 s 之后，她在 3D 世界里只以痕迹出现：剪影、影子、线、光。
凡是看得见细节的地方，都是你的原画本身（只抠图、提线、调色，不重画）。

情绪弧线：影 → 线 → 光 → 色。最后在"我眼中"拼合成完整的原画。

四种融合手段：

1. 原画立牌：原画抠出的人形作为立牌站在 3D 世界里。
   - 纯黑剪影，只有头发按原画发丝发光（呼应水墨段"只有头发是橙色"）。
   - 立牌在镜面地面上有真实倒影和投影。
   - 轮廓光与场景逆光同步。
   - 镜头绕行时立牌始终朝向镜头：她永远面向"我"。
2. 模型只当"看不见的身体"：3D 模型对相机不可见，只投下真实的影子。用于棋局（L13），细节为零。
3. 2.5D 浮雕：原画按人形轮廓膨胀出深度。线稿和光沿这层浮雕铺开，镜头横移时有真实的视差。
4. 错位拼合（anamorphic）：
   - 原画碎成约 800 片玻璃，散落在纵深里。每一片都沿着"我的视线"放置。
   - 只有镜头回到"我的眼睛"那一点时，碎片才严丝合缝地拼回完整原画。
   - 拼合落在 L16 的「眸」字上，全片唯一一次全彩也在这一刻出现。

### 代码特效字体：「代码编译成书法」

3D 字（L11–L16）统一的生命周期：

1. 源码（字前 0.25 s）：先浮现字形的矢量骨架。
   - 曲线锚点画成小方块，控制柄画成小圆加细线。
   - 外加包围框和等宽字体的码位标签，如 `U+7D55`，像字体编辑器。
2. 描边：光笔沿轮廓描线，经过的锚点逐个点亮。
3. 编译：字身点亮，骨架淡出。
4. 退出：燃烧成光尘（不变）。

逐镜点缀：

- L12：光带是代码丝。
- L13：棋子落下时亮起 SGF 坐标，如 `B[jd]`。
- L15：字身按方块渲染式填充。
- L16：保持安静，不加代码元素。

2D 字幕（L1–L10，cinema 样式）只加一点：

- 解码：字落定前，字位里快速闪过几个候选字，像模型在采样。
- 光标：一根终端光标跟着人声前进，停顿时闪烁。
- 码位注音：每个字下方用 13 px 等宽灰字标出它的 Unicode 码位，像注音一样。

## 渲染与合成

- Blender 5.2 Eevee，1920×1080，24 fps。帧号 = 歌曲秒数 × 24。
- 场景由 `pv/blender/` 下的脚本搭建：数据驱动，可以反复重建。
- 后台命令行渲染，渲染期间不占用 MCP。
- `film.py` 合成：
  - 0–31.1 s 不变。
  - 31.1 s 之后用 Blender 序列帧。
  - 叠加层：L6–10 字幕、HUD、小吉祥物、光标。
